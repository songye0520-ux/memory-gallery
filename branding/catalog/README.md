# In-app catalog assets

Upload these into Developer Portal → Developer Settings → In-app catalog → **Your assets**.

Image rules used here (from Media guidelines):

- Formats: JPG or PNG (preferred)
- Featuring / fallback: **1500×1000** (min 1000×667), 3:2
- Tile image: **560×256** (min 280×128)
- File size: aim ≤ **800 KB**, max 3 MB
- High contrast; readable in greyscale; no tiny text logos

## Files to upload

| Portal field | File | Size |
|---|---|---|
| Promotional icon | `promotional-icon.jpg` | 1024×1024, ~197 KB |
| Featuring asset | `featuring.mp4` | 1500×1000 MP4, ~6s |
| Fallback asset | `fallback.jpg` | 1500×1000, ~150 KB |
| Tile image | `tile-image.png` (preferred) or `tile-image.jpg` | 560×256 |
